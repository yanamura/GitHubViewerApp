# Xcode MCP 接続確認

Xcode MCP (`.mcp.json` の `xcode` サーバー) に接続できていると、ビルドやプレビュー確認などをXcode経由で行える。
接続できていない状態で気づかずに実装を進めると、後から検証手段が足りないと分かって手戻りになるため、コードを変更する前に一度だけ接続状態を確認する。

## 手順

### 1. 接続状態を確認する

`ToolSearch` で `xcode` を検索し、`mcp__xcode__` で始まるツールが見つかるかを確認する。

- 見つかる → 接続済み。何も聞かずにそのまま作業を続ける。確認結果を長々と報告しない（「Xcode MCP 接続済み」の一言で十分）。
- 見つからない → 未接続。手順2へ進む。

Bash で `claude mcp list` を実行して判定しない。設定上の状態ではなく、いま Claude が実際に使えるかどうかを知りたいため。

### 2. 未接続なら、継続するかをユーザーに確認する

`AskUserQuestion` で、Xcode MCPに接続できていないことを伝え、次のどちらにするかを尋ねる。

- **Xcode MCPなしで継続する**: ビルドやテストは `xcodebuild` で行う（コマンドは `swift-testing` スキル参照）。
- **中断する**: ユーザーがXcode MCPを接続し直してから、改めて依頼する。

接続方法や原因の説明までは踏み込まない。ユーザーが求めたときだけ案内する。

### 3. 回答に従う

- 継続 → 本来の作業を進める。同じ作業の間は再度確認しない（何度も聞くと作業の邪魔になるため）。
- 中断 → コードは変更せず、作業を止めてユーザーの再接続を待つ。
