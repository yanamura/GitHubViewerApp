# GitHub Viewer for iOS 機能仕様書

## 1. アプリケーション概要
GitHub REST APIを利用してリポジトリの探索（トレンド閲覧）・キーワード検索・詳細確認（README表示等）を行い、気に入ったリポジトリをローカルにお気に入り保存できるシンプルなiOSネイティブアプリ。

---

## 2. 画面・タブ構成

```
[RootTabView]
├── Tab 1: Explore (トレンド / 注目のリポジトリ)
├── Tab 2: Search (キーワード検索)
├── Tab 3: Favorites (ローカルお気に入り)
└── Tab 4: Settings (APIトークン設定)
```

---

## 3. 各画面の機能要件

### 3.1. Explore 画面（トレンド・発見）
| 項目 | 仕様 |
| :--- | :--- |
| **初期表示** | 直近1ヶ月でStar数の多い人気リポジトリを一覧表示（`q=created:>YYYY-MM-DD sort:stars`） |
| **言語フィルタ** | セグメントまたはメニューで主要言語を切り替え（All, Swift, Kotlin, Rust, Python, TypeScript 等） |
| **一覧表示項目** | オーナーアイコン、リポジトリ名、説明文、主要言語、Star数、Fork数 |
| **Pull to Refresh** | 下スワイプによるデータ再取得 |
| **画面遷移** | セルタップで「リポジトリ詳細画面」へ遷移 |

### 3.2. Search 画面（リポジトリ検索）
| 項目 | 仕様 |
| :--- | :--- |
| **検索バー** | `.searchable` を利用したキーワード入力（Enter確定、または入力停止後のデバウンス検索） |
| **ソート** | 不要（APIデフォルト適合度順） |
| **ページネーション** | リスト最下部到達時に次ページを自動取得（Infinite Scroll） |
| **空状態・エラー表示** | 0件時（EmptyView）、通信エラー時（リトライボタン付きErrorView）の表示 |
| **画面遷移** | セルタップで「リポジトリ詳細画面」へ遷移 |

### 3.3. リポジトリ詳細画面（共通遷移先）
| 項目 | 仕様 |
| :--- | :--- |
| **ヘッダー領域** | オーナー名 / リポジトリ名、アバター、説明文、作成日・更新日 |
| **メトリクス** | Star数、Fork数、Open Issues数、ライセンス表記 |
| **アクション** | **お気に入り登録 / 解除ボタンのみ**: ナビゲーションバーの星アイコンタップでローカル永続化状態をトグル |
| **README表示** | API (`/repos/{owner}/{repo}/readme`) からRaw Markdownを取得し、ネイティブレンダリング |

### 3.4. Favorites 画面（お気に入り）
| 項目 | 仕様 |
| :--- | :--- |
| **一覧表示** | ローカルに保存されたリポジトリを登録順で一覧表示 |
| **並び替え** | 不要 |
| **削除機能** | スワイプアクションによるお気に入り解除 |
| **画面遷移** | セルタップで「リポジトリ詳細画面」へ遷移 |

### 3.5. Settings 画面（設定）
| 項目 | 仕様 |
| :--- | :--- |
| **Personal Access Token (PAT)** | - PAT入力用TextField（セキュア入力対応）<br>- Keychainへの保存・読み込み・削除<br>- 保存時に疎通確認を実施 |
| **その他機能** | キャッシュ管理、アプリ情報、レートリミット表示は除外 |

---

## 4. エラーハンドリング & Concurrency規約

1. **レートリミット対策**:
   - HTTP 403 (Rate Limit Exceeded) 検知時、SettingsタブでのPAT登録を促すアラートを表示。
2. **Swift Concurrency**:
   - API通信およびローカル永続化処理は `async/await` で非同期処理。
   - Viewに接続するViewModelは `@MainActor` を適用し、スレッド安全性を担保。
3. **オフライン対応**:
   - 特段のキャッシュ・オフライン閲覧機能は実装しない（エラー時はリトライを促す標準表示）。
